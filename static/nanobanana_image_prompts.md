# Nanobanana Image Prompts

格安SIMサイトで使う想定の生成画像プロンプトです。

## 1. Hero Image

用途:
- トップページのヒーロー背景

Prompt:
```text
Use case: photorealistic-natural
Asset type: website hero
Primary request: a premium editorial-style image for a Japanese mobile plan comparison website
Scene/backdrop: clean modern workspace with smartphone, laptop, subtle telecom charts, soft daylight, premium but approachable atmosphere
Subject: a Japanese adult reviewing mobile plan choices on screen, calm and confident expression
Style/medium: realistic editorial photography
Composition/framing: wide composition with strong negative space on the left for headline text
Lighting/mood: bright natural daylight, trustworthy, clean, modern
Color palette: white, navy, soft blue, subtle cyan accents
Constraints: no logos, no carrier names, no visible brand marks, no text, no watermark
Avoid: cluttered desk, exaggerated cyberpunk look, dark scene, stock-photo smile
```
